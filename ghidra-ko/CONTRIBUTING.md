# 기여 방법
새 번역은 `translations/ko.json`에 정확한 소스 앵커와 함께 추가합니다.
표시 문자열만 수정하고 파일명, 식별자, setName, 콜백, enum, 비교에 쓰이는 문자열은 유지합니다.
문맥, 접근성, 단축키, UI 폭을 확인하고 실제 소스 검사와 GUI 결과를 기록해 주세요.
새 버전은 별도 체크아웃에서 차이를 검토한 뒤 버전·커밋·SHA-256을 갱신합니다.
`--allow-unverified` 통과만으로 지원 버전을 추가하지 마세요.
기여는 해당 파일의 라이선스(이 저장소의 새 파일은 Apache-2.0)에 따릅니다.
